# 📊 Digital Payment Analysis using RTGS and NEFT
## 📌 Project Overview

This project analyzes digital payment trends in India using RTGS (Real Time Gross Settlement) and NEFT (National Electronic Funds Transfer) datasets. The goal is to understand transaction patterns, identify top-performing banks, and predict future transaction values using machine learning.

---

## 🎯 Objectives

* Analyze monthly transaction growth
* Compare inward and outward transactions
* Identify top 10 banks
* Perform trend analysis
* Evaluate digital payment impact on economy
* Predict future transactions using Linear Regression

---

## 📂 Dataset

The dataset is sourced from the Reserve Bank of India (RBI).

🔗 https://www.rbi.org.in/Scripts/PSIData.aspx

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

---

## 📊 Exploratory Data Analysis

* Data cleaning and preprocessing
* Aggregation and grouping
* Visualization using graphs

---

## 🤖 Machine Learning

* Linear Regression model used
* Model evaluation using MAE and R² score

---

## 📈 Results

* Increasing trend in digital payments
* Balanced inward and outward transactions
* Major banks dominate transaction volume

---

## 📌 Conclusion

Digital payment systems like RTGS and NEFT are rapidly growing and contributing significantly to India's economy.
